# 学习路线导航

> 系统学习先判断基础，再选一条主线。开发岗、算法岗是两条主线，其余四份路线按需使用，不必全部学完。

## 推荐入口

### 第一步：判断你的基础

| 你的状态 | 下一步 |
|:---|:---|
| 第一次接触 Agent，还不清楚 workflow、agent 与工具调用的关系 | 进入[新手导航](../00-getting-started/README.md)，按“学习地图 → 七日计划”开始，完成后回到本页选择主线 |
| 已有 Agent 基础，理解基本概念并做过简单的工具调用或 Agent demo | 直接在下方开发岗、算法岗两条主线中选一条 |

**新手实践需要基本编程和 API 知识**：能阅读和修改基本程序、理解请求与响应，并完成一次模型 API 调用。基础不足时，先读学习地图，再补齐这些能力后动手。

### 第二步：选择一条主线

| 主线 | 适合你的目标 | 从这里继续 |
|:---|:---|:---|
| **开发岗主线** | 搭建 Agent 应用，接入工具与数据，完成工程交付 | [开发工程师学习路线](./learning-roadmap-development.md) |
| **算法岗主线** | 深入模型原理、训练与优化，通过实验验证方法 | [算法工程师学习路线](./learning-roadmap-algorithm.md) |

按所选路线的阶段顺序学习并完成实践；遇到基础缺项时回补对应内容，不需要同时走完两条主线。

## 学到一个阶段后去哪里

- 需要实践验证：进入[项目导航](../../projects/README.md)选择项目，边做边回查所选主线。
- 准备面试：进入[面试与求职导航](../04-interview/README.md)，结合求职产出检查材料查漏补缺。
- 希望开展研究：进入[科研前沿入口](../06-research-frontiers/README.md)选择研究专题。
- 只需查找具体技术：进入[文档总导航](../README.md)按主题检索。
