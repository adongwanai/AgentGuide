# 世界模型面试指南

> 会生成逼真视频不自动等于拥有可用于决策的世界模型。面试的关键是：状态表示什么、怎样预测动作后果、误差如何影响规划、怎样闭环验证。

---

## 📌 本节目标

- 给世界模型一个可操作、可证伪的定义。
- 串起 POMDP、表征、动力学、奖励 / 终止、规划和策略学习。
- 区分视频生成、模型式强化学习、具身世界模型和 Agent 环境模型。
- 讨论多步误差、不确定性、OOD、Sim-to-Real 与闭环评测。

## 💡 核心概念

在部分可观测环境中，世界模型通常从历史构建潜状态，并预测动作产生的后果：

```text
z_t = Encoder(o_≤t, a_<t)
z_(t+1) ~ Dynamics(z_t, a_t)
o_hat, r_hat, done_hat = Decoder(z_(t+1))
```

它的价值不在“重建得像”，而在于能否保留对目标任务足够的信息，让策略在模型中进行预测、搜索、规划或数据生成，并在真实环境中获得更好的结果。

### 定义边界

| 系统 | 是否一定是世界模型 | 判断关键 |
|:---|:---:|:---|
| 视频生成模型 | 否 | 是否接收动作、保持状态并支持决策 |
| 环境模拟器 | 可能 | 保真度、可交互性与任务相关状态 |
| 动力学模型 | 是核心组成 | 是否预测动作条件下的状态转移 |
| 用户模拟器 | 可以是 | 是否用于交互策略评估或优化 |
| LLM 工具结果预测器 | 可以是 | 是否建模工具 / Web / 代码环境并用于规划 |
| 数字孪生 | 常包含 | 是否同步真实系统并支持反事实决策 |

## 🔍 深入理解

### 1. 表征怎样选

| 表征 | 优点 | 风险 | 适合场景 |
|:---|:---|:---|:---|
| Pixel / 原始观测 | 信息保留多 | 成本高，预测难度大 | 视觉保真与生成 |
| Latent state | 紧凑、利于规划 | 可能丢掉任务关键信息 | 控制、具身、长 rollout |
| Object / Graph | 结构与关系清晰 | 感知和建图困难 | 多物体交互、可解释规划 |
| Symbolic / Program | 可执行、可约束 | 获取表示成本高 | 规则强、精确验证任务 |
| Hybrid | 兼顾感知与结构 | 系统复杂、接口难训 | 复杂开放环境 |

最好的表示不是最容易重建输入的表示，而是对任务决策充分、对无关因素不敏感，并能表达不确定性。

### 2. 规划方式

- **MPC / CEM / MPPI**：在模型中采样动作序列，执行第一步后重新规划。
- **树搜索 / MCTS**：显式扩展候选未来，用价值与先验控制搜索。
- **Imagined rollout**：在潜空间生成轨迹训练 actor / critic。
- **Policy distillation**：把昂贵规划器行为蒸馏进快速策略。

MPC 的反复重规划能缓解模型误差，但增加在线计算；长 imagined rollout 成本低，却会放大模型偏差。规划 horizon 应与模型的有效预测范围匹配。

### 3. 多步误差与不确定性

一步预测指标好不代表长程规划好。误差会随着自回归 rollout 累积，策略还可能主动寻找模型的漏洞。常见治理：

- 多步训练、overshooting 或闭环 rollout 训练。
- 模型 ensemble、分布预测和校准。
- OOD 检测与“不知道”机制。
- 不确定性惩罚、保守规划和短 horizon MPC。
- 定期回到真实环境纠偏。
- 对模型中高回报轨迹做真实环境复核。

### 4. 评测必须包含闭环

| 评测 | 能说明什么 | 不能单独说明什么 |
|:---|:---|:---|
| 重建 / 感知质量 | 表征是否保留观测 | 是否能预测动作后果 |
| 一步预测误差 | 局部动力学质量 | 长程稳定和控制性能 |
| 多步 rollout | 误差累积与一致性 | 策略是否会利用模型漏洞 |
| 下游控制回报 | 决策价值 | 模型是否物理真实 |
| 反事实 / 干预测试 | 动作因果一致性 | 开放世界泛化 |
| 真实闭环成功率 | 最终实用性 | 具体误差来自哪个模块 |

## 🎯 面试中如何考

### 高频必答

1. **什么是世界模型？怎样和视频生成模型区分？**
   - 回答轴：动作条件状态转移、持久状态、任务价值和闭环决策。

2. **为什么世界模型常在 latent space 里学习？**
   - 回答轴：压缩无关细节、降低 rollout 成本、保留任务充分信息。

3. **世界模型包含哪些子模型？**
   - 回答轴：表示 / 状态估计、动力学、观测、奖励、终止、不确定性。

4. **模型式 RL 与无模型 RL 的主要取舍？**
   - 回答轴：样本效率和规划能力 vs 模型偏差与计算复杂度。

5. **为什么一步预测准，规划仍可能失败？**
   - 回答轴：分布偏移、误差累积、任务信息丢失、策略利用模型漏洞。

6. **怎样选择 rollout horizon？**
   - 回答轴：有效预测范围、重规划频率、计算预算和不确定性。

7. **世界模型如何表达多种可能未来？**
   - 回答轴：随机 latent、分布预测、ensemble、生成式动力学。

8. **什么是 Sim-to-Real gap？**
   - 回答轴：视觉、动力学、传感器、延迟、控制接口与行为分布差异。

### 深挖与设计题

9. 如何判断 latent state 是否对控制“足够”？
10. 世界模型与 value model 的边界是什么？MuZero 类方法为什么不追求像素重建？
11. 策略在模型中发现高回报、真实环境却失败，怎样诊断？
12. 机器人接触、碰撞这类高频事件为什么难建模？
13. 怎样为 Web / GUI Agent 构建环境模型？状态和动作如何定义？
14. 使用世界模型替代真实 Agentic RL 环境，最大的偏差来源是什么？
15. 如何用不确定性决定“继续想象”还是“回到真实环境”？
16. 持续变化的开放世界中，模型如何更新而不遗忘？
17. 多 Agent 世界模型需要额外建模什么？
18. 设计一个能证明世界模型带来实际决策收益的消融实验。

## 🧪 项目设计模板

> 为一个浏览器 Agent 构建轻量世界模型，预测点击后的页面状态并用于候选动作筛选。

最小实验：

1. 定义页面状态、可见观测、动作和终止条件。
2. 收集真实交互轨迹，按网站或时间切分。
3. 比较无模型 baseline、一步预测筛选和多步规划。
4. 同时评估状态预测、任务成功、真实环境调用次数和成本。
5. 单独测试页面变化、弹窗、登录态和不可逆动作。
6. 展示一个模型预测错误导致规划失败的轨迹，并加入不确定性门禁。

## ✅ 面试前自检

- [ ] 我的定义包含动作、状态转移和下游决策价值。
- [ ] 我能解释任务充分表示与像素重建的差别。
- [ ] 我知道模型误差如何被规划器放大。
- [ ] 我准备了闭环控制 / 任务指标，不只是一阶预测损失。
- [ ] 我能画出模型、规划器、策略与真实环境的数据流。
- [ ] 我有一个 OOD、Sim-to-Real 或模型 exploitation 失败案例。
