# 图像生成面试指南

> 图像生成面试通常沿“表示 → 训练目标 → 采样 → 条件控制 → 数据评测 → 推理部署”逐层追问。只会背扩散公式，很难回答真实系统的取舍。

---

## 📌 本节目标

- 串起 VAE、扩散、Flow Matching、Transformer 和条件控制。
- 理解训练参数化、噪声调度、采样器和 guidance 的相互影响。
- 能设计数据治理、质量 / 对齐评测和推理优化。
- 能讨论一致性、文字生成、可控编辑、版权与安全边界。

## 💡 核心概念

### 一条端到端链路

```text
图文 / 编辑数据 → 清洗、去重、caption 与审美过滤
              → 文本编码 + 图像 latent 表示
              → 生成模型训练
              → 条件控制与采样
              → 解码、后处理与安全检查
              → 人评 / 自动评测 / 线上反馈
```

### 主流建模路线

| 路线 | 核心思想 | 优势 | 主要挑战 |
|:---|:---|:---|:---|
| Autoregressive | 将图像离散化后按序生成 token | 与 LLM 范式统一、条件建模自然 | 序列长、解码慢、tokenizer 上限 |
| Diffusion | 学习逐步去噪或 score | 质量高、生态成熟、控制灵活 | 多步采样、训练与采样细节多 |
| Flow Matching | 学习连接噪声与数据的连续速度场 | 路径更直接、便于 ODE 采样 | 路径 / 参数化和高效求解仍需设计 |
| Hybrid | 组合离散规划与连续生成 | 可兼顾语义和细节 | 系统复杂、训练与部署成本高 |

Latent 生成先用 autoencoder 压缩图像，再在低维空间建模，能显著降低计算；代价是细节、文字和高频结构可能受 tokenizer / decoder 上限影响。

## 🔍 深入理解

### 1. 扩散与流的统一视角

面试回答不必只推公式，更重要的是说清：

- 前向过程如何从数据走向简单分布。
- 网络预测的是噪声、干净样本、velocity 还是 vector field。
- 不同参数化怎样改变各噪声区间的学习权重和稳定性。
- 采样器怎样在质量、步数、随机性和可复现性之间取舍。
- 训练路径与推理数值求解器不匹配时会发生什么。

### 2. 条件与可控生成

- 文本条件：cross-attention、联合序列或调制层。
- Guidance：在条件遵循和图像多样性之间调节。
- 结构控制：边缘、深度、姿态、分割、布局和参考图。
- 编辑：mask / inpainting、指令编辑、特征注入和 inversion。
- 一致性：人物身份、物体关系、风格和多张图的时序 / 叙事连续。

Guidance 太强可能导致过饱和、多样性下降或细节异常；控制信号太强可能破坏文本语义。好的回答要给出冲突时的优先级和评测方法。

### 3. 数据比“换模型”更常决定上限

关注：

- 图像质量、分辨率、压缩伪影与水印。
- Caption 的细粒度、事实性、OCR 和关系描述。
- 重复 / 近重复、人物和风格过度集中。
- 许可、肖像、隐私、未成年人和敏感内容。
- 训练 / 测试泄漏与 benchmark 污染。
- 数据混合比例、课程和难度分布。

### 4. 评测矩阵

| 维度 | 方法 | 注意点 |
|:---|:---|:---|
| 视觉质量 | 人评、无参考质量模型、伪影统计 | 审美偏差与领域差异 |
| 文本对齐 | 图文相似度、VQA / 结构化问答 | 高相似不等于关系正确 |
| 组合性 | 数量、属性绑定、空间关系 | 需要细粒度 prompt 集 |
| 多样性 | 分布、重复率、同 prompt 变体 | 与对齐 / 质量有冲突 |
| 身份一致 | 人脸 / 特征一致性 + 人评 | 隐私、公平与误用风险 |
| 文字生成 | OCR 正确率、版式与可读性 | 多语言和字体切片 |
| 安全 | 红队、违规生成和拒绝误伤 | 输入输出双侧检查 |
| 性能 | 延迟、步数、显存、成本 | 必须固定分辨率和采样设置 |

## 🎯 面试中如何考

### 高频必答

1. **扩散模型训练和采样分别在做什么？**
   - 回答轴：前向加噪、反向预测、参数化、采样迭代。

2. **为什么在 latent space 生成？**
   - 回答轴：降低空间尺寸与算力；代价是压缩瓶颈和细节损失。

3. **ε、x0、v 参数化有什么区别？**
   - 回答轴：预测目标、噪声区间权重、数值尺度与训练稳定。

4. **Flow Matching 与扩散是什么关系？**
   - 回答轴：概率路径、速度场 / score、ODE / SDE 视角和采样。

5. **Classifier-free guidance 为什么有效？**
   - 回答轴：条件与无条件预测的组合；对齐、多样性和伪影取舍。

6. **U-Net 与 DiT 如何选？**
   - 回答轴：归纳偏置、scaling、token 数、分辨率和系统效率。

7. **怎样提升 prompt 中数量和空间关系的正确率？**
   - 回答轴：caption / 数据、布局或结构条件、训练目标、rerank 与细粒度评测。

8. **如何减少采样步数？**
   - 回答轴：更高阶求解、蒸馏 / consistency、路径设计；同时检查质量和多样性。

### 深挖与设计题

9. 训练 loss 继续下降，但人评质量停滞，怎样分析？
10. 模型生成文字经常拼错，瓶颈可能在 tokenizer、数据还是生成主干？
11. 如何做主体一致的多图故事生成？
12. Inpainting 为什么容易出现边界和光照不一致？
13. 数据去重太强会不会损害长尾概念学习？
14. 如何为电商图生成建立离线到线上评测？
15. 蒸馏后模型更快但多样性下降，如何证明并修复？
16. 同一模型怎样同时服务高质量离线创作和低延迟在线预览？
17. 如何定位某个概念来自训练数据记忆还是组合泛化？
18. 图像生成中的安全过滤放在输入、生成过程还是输出？

## 💻 白板题

请写出一个高层训练循环，并明确哪些组件冻结、如何采样时间步、条件 dropout 在哪里发生：

```python
image_latent = vae.encode(image).detach()
condition = text_encoder(caption)
t = sample_timestep(batch_size)
noise = sample_noise_like(image_latent)
noisy_latent, target = build_training_pair(image_latent, noise, t)
prediction = denoiser(noisy_latent, t, maybe_drop(condition))
loss = weighted_objective(prediction, target, t)
```

面试官更关心你能否说明 `target`、`weighted_objective` 和条件丢弃的选择，而不是背出完全一致的函数名。
